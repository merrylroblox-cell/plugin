# HealNote V2

Un plugin Paper inspiré de Death Note.

## Présentation

HealNote V2 est un plugin Paper qui ajoute des événements importants sur le serveur grâce à trois livres spéciaux et un système de bannissement permanent.

## Fonctionnalités

### Livres Spéciaux

1. **Death Note** - Condamne un joueur à mort
2. **Heal Note** - Sauve un joueur condamné (le sauveur meurt)
3. **Deban Book** - Lance un Défi du Destin pour débannir un joueur

### Composants

- **Page Maudite** - Ingrédient de craft pour les livres
- **Gardien du Destin** - Boss pour le Défi du Destin

## Installation

1. Compiler : `mvn clean package`
2. Placer le JAR dans le dossier `plugins/`
3. Redémarrer le serveur

## Version

- Version: 2.0.0
- Minecraft: 1.20+
- Papier: Latest
